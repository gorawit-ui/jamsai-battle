# ร่าง Google Sheet ผลการตอบรายบุคคล

ไฟล์ [`jamsai-battle-results-template.xlsx`](./jamsai-battle-results-template.xlsx) — สร้างจาก `scripts/sheets/build_export_template.py`

## วิธีเปิดเป็น Google Sheet

1. เปิด Google Drive → **New → File upload** → เลือกไฟล์ `.xlsx` นี้
2. คลิกขวาที่ไฟล์ → **Open with → Google Sheets** → **File → Save as Google Sheets**
3. ส่งลิงก์ Sheet ให้ Claude ตรวจว่าสูตรคำนวณถูกครบ

> สูตรเขียนสำหรับ **Google Sheets** (ARRAYFORMULA · FILTER · XLOOKUP · BYROW) — เปิดใน Excel บางช่องจะ error

## แท็บ

| แท็บ | ใครเขียน | เนื้อหา |
|---|---|---|
| วิธีใช้ | — | คำอธิบาย |
| **รายบุคคล** | สูตร | เลือกชื่อ → คะแนน แรงค์ % ถูก ผิด→ถูก/ผิดซ้ำ/ถูก→ผิด · ผลรายบท 10 บท · รายระดับ · ประวัติรายวัน · ข้อที่ตอบไม่ถูก |
| ภาพรวม | สูตร | คะแนนทีม (หารสมาชิกทั้งหมด + โบนัสทีม) · ผลรายบท · คนเล่นรายวันแยกทีม |
| รายข้อ | สูตร | % ตอบผิดต่อคำถาม · ติดป้าย "ควรทบทวน" เมื่อผิดเกินเกณฑ์ |
| Answers | ระบบ | 1 แถวต่อคำตอบ 1 ข้อ |
| Daily | ระบบ | 1 แถวต่อคนต่อวัน · คะแนนเกม/รวมวันเป็นสูตรตาม brief 5.1–5.6 |
| People | ระบบ (A–C) + สูตร | 1 แถวต่อคน |
| Survey | ระบบ | รอคำถามจาก HR |
| ตั้งค่า | HR | เกณฑ์แรงค์ · เกณฑ์ข้อควรทบทวน · โบนัสทีม |

ข้อมูลในไฟล์เป็น **ตัวอย่างสมมุติ** (6 คน · 5 วัน) ให้เห็นว่าหน้าวิเคราะห์ทำงานอย่างไร
