# Reading Rally — Rank Frames v1

ไฟล์ PNG แยกครบ 8 Rank พร้อมช่องภาพและด้านนอกโปร่งใสจริง มีชื่อ Rank ติดกับกรอบ
กราฟิกสร้างด้วยเครื่องมือสร้างภาพในตัว โดยใช้แบบที่เลือกไว้เป็นภาพอ้างอิง
เก็บประกายและแสงในภาพไว้ตามระดับ Rank ส่วนภาพเคลื่อนไหวเพิ่มด้วย CSS

## เริ่มดูตัวอย่าง
แตก ZIP แล้วเปิด preview.html ในเบราว์เซอร์ เลือกรูปจากเครื่องได้ทันที
ตัวอย่างไม่มีการอัปโหลดรูปออกจากเครื่อง และใช้ได้โดยไม่ต้องเชื่อม Slack
ดูได้ทั้งขนาดโปรไฟล์ 210px และ Leaderboard 64px พร้อมเปิด/ปิดวิ้บวับ

## ส่งให้ Claude Code
ให้ส่งทั้งโฟลเดอร์นี้ พร้อมข้อความใน CLAUDE_HANDOFF.md
frames/ มี PNG ต้นฉบับแต่ละ Rank ไม่ใช่ภาพรวมที่ต้องตัดแยก
asset-manifest.json มีขนาดจริง ตำแหน่งช่องรูปและ clip-path ของแต่ละภาพ
rank-avatar.js และ rank-avatar.css เป็นตัวอย่างประกอบที่ไม่ต้องติดตั้งไลบรารี

## วิธีซ้อนรูป
1. ใช้รูปจาก Slack ที่ระบบล็อกอินของโครงการมีสิทธิ์อ่านอยู่แล้ว
2. แสดงรูปเป็นเลเยอร์หลังด้วย object-fit: cover ไม่ยืดหรือบีบภาพ
3. ใช้ photo.left/top/width/height/clipPath ของ Rank นั้นจาก manifest
4. วาง PNG เต็มกรอบเป็นเลเยอร์หน้า; ไม่ใช้พื้นหลังสีฟ้าหรือสีดำเติมในช่อง
5. รูปและกรอบอยู่ในกล่อง aspect-ratio:1 เดียวกัน สเกลพร้อมกัน

ตำแหน่งช่องรูปแต่ละ PNG ต่างกันเล็กน้อยตามรายละเอียดงานวาด จึงมีค่าประจำ Rank
ขนาดรูปจาก Slack ไม่จำเป็นต้องเท่ากับขนาด PNG; เบราว์เซอร์ครอปให้พอดีด้วย object-fit
photo.clipPath คำนวณจากช่อง alpha กลางภาพและเผื่อใต้ขอบเล็กน้อยเพื่อกันรอยต่อ
อย่าลบ alpha หรือแปลงเป็น JPG เพราะจะเสียความโปร่งใส

## เอฟเฟกต์
E เรียบ ไม่มีแอนิเมชัน; D มีประกายอัญมณีอยู่ในภาพ ไม่มีแอนิเมชัน
C/B/A มีดาวกะพริบช้า ๆ เพิ่มบนเว็บ
S/SSS/Legendary มีดาวและความสว่างกรอบขึ้นลงเล็กน้อย
ไม่หมุนหรือขยายตัว PNG เพราะจะทำให้กรอบไม่ตรงกับรูป
ขนาดต่ำกว่า 96px ปิดดาวเพิ่ม ลดความรก แต่คงประกายใน PNG
รองรับ prefers-reduced-motion และ motion:false
PNG ไม่ได้ขยับด้วยตัวเอง ต้องใช้ CSS/JS ที่แนบหรือวิธีเทียบเท่า

## คะแนน
E 0–49 / D 50–99 / C 100–149 / B 150–199 / A 200–249 /
S 250–299 / SSS 300–349 / Legendary ตั้งแต่ 350
getRank ใช้คะแนนรวมสะสมเท่านั้น ตัวอย่างนี้ไม่เพิ่ม/แก้คะแนน ไม่ใช่ระบบคิดโบนัส
กติกาจำกัดคะแนนมินิเกม 10 คะแนนต่อวันให้คงอยู่ฝั่งระบบเกมเดิม

## ขนาดบนเว็บ
กรอบทั้งหมดมีส่วนตกแต่งที่ยื่นออกจากช่องรูป จึงควรเผื่อพื้นที่เลย์เอาต์
64px เหมาะเป็นตัวอย่างขนาดเล็ก แต่ชื่อ Legendary บนภาพจะเล็ก ให้มีข้อความ Rank แยก
ในข้อมูลแถวตารางหรือ tooltip ที่เข้าถึงได้ด้วย keyboard ด้วย
รูปแหล่งข้อมูลของผู้ใช้ยังอยู่ภายใต้นโยบายการเข้าถึงและอายุ URL ของ Slack เดิม

## ตรวจแล้ว
ไฟล์ทั้ง 8 เป็น RGBA มี alpha=0 ที่กลางภาพและมุมนอกภาพ
เก็บ PNG โดยไม่แก้ไขพิกเซลจากไฟล์ที่สร้าง; manifest และตัวอย่างช่วยจัดแนวตอนแสดงผล

ตรวจ syntax JavaScript และจุดเปลี่ยน Rank แล้ว; สภาพแวดล้อมนี้ไม่มี browser executable จึงยังไม่ได้ทดสอบ HTML ด้วยเบราว์เซอร์จริง กรุณาตรวจบนเว็บโครงการหลังเชื่อมต่อ
